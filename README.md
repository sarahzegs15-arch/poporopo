# Poporopo — Nuestro mundo

Pequeña aventura web inspirada en los juegos de bloques. Está hecha con HTML, CSS y JavaScript puro, sin dependencias de servidor.

## Probar localmente
1. Descarga y descomprime la carpeta.
2. Abre `index.html` en un navegador moderno.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube `index.html`, `style.css` y `game.js` a la raíz del repositorio.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. Espera a que GitHub Pages publique el sitio.

## Controles
- PC: WASD o flechas para moverse; E o Enter para interactuar.
- Celular: usa la cruceta y el botón de acción.
- El progreso se guarda localmente en el navegador del dispositivo.

## Personalizar el mensaje final
Abre `game.js` y busca el objeto con `id: "house"`. Edita el texto de su propiedad `text`.
